Order By All keyword is not correctly parsed 
Hello,

In duckdb the ALL keyword indicates that the output should be sorted by every column in order from left to right. The direction of this sort may be modified using either ORDER BY ALL ASC or ORDER BY ALL DESC and/or NULLS FIRST or NULLS LAST.

Using `sqlglot 25.5.1`, I was not able to parse correctly the "all" keyword.                                

**Fully reproducible code snippet**
```python 
import sqlglot

sql = """SELECT *
FROM test
ORDER BY ALL DESC;"""

parsed_sql = sqlglot.parse_one(
    sql=sql,
    read=sqlglot.Dialects.DUCKDB,
).sql(sqlglot.Dialects.DUCKDB)

print(parsed_sql)
```
```
>>> SELECT * FROM test ORDER BY "ALL" DESC
```

The output query is not correct and running it will produce an error.
The correct output should be:
```
>>> SELECT * FROM test ORDER BY ALL DESC
```

**Official Documentation**
https://duckdb.org/docs/sql/query_syntax/orderby.html
