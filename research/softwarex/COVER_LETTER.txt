Dear Editors of SoftwareX,

Please consider "ZeroRun: Reproducible test-result reuse for AI coding tools" as an Original Software Publication.

ZeroRun is a Python execution component and evaluation kit for deterministic test-result reuse in AI coding-tool integrations. Its command-line and repository-bound MCP interfaces distinguish previous successful test status from fresh execution. Researchers can inspect reuse eligibility, request fresh validation when needed, and measure whether avoided execution outweighs checking and miss costs.

The software contribution combines an explicit result-origin contract, a whole-file hit path that avoids execution staging, and source-bound validation tools. Unlike caches of arbitrary tool effects or agent trajectories, it rechecks declared local test inputs and returns status metadata without replaying historical transcripts. The article distinguishes this operating contract from existing systems; it does not claim a new caching algorithm or language-model inference acceleration.

Evaluation separates controlled real-library measurements from public AI-trajectory observations. Input-inventory checks and fresh-oracle comparisons exercise changes, failures, repetition and restoration. Complete-sequence costs retain unfavorable outcomes rather than reporting only fast hits. The fixed trajectory sample shows why repeated command text alone cannot establish reuse eligibility: intervening state uncertainty is not counted as an agent cache hit. Raw measurements, exclusions, interruptions and recovery records accompany the article.

The AI-client application is demonstrated on an isolated synthetic fixture. One prospective configuration completed the four-call core lifecycle before a later unsupported-argument request failed; this and earlier failed configurations are preserved. A separately frozen API-guided demonstration passed two model-selected validation decisions, two fresh oracles and six no-tool interpretations, including fresh failure and rejection of reused status when fresh diagnostics were required. Discovery, readiness and seeding were non-model setup, not additional model decisions.

The public package provides an operator guide, API card, manifest reference and account-free Linux quickstart, which passed from a fresh external installation. These bounded results do not establish independent adoption, autonomous issue resolution, end-to-end AI speedup or a causal documentation effect.

Code and reproducible evidence are available at https://github.com/floxy-21/zerorun-research with immutable version bindings and applicable licenses. The manuscript discloses substantial AI assistance and potential commercialization; no external funding was received. Jishan Kapoor is the sole human author. We request assessment as reusable research software with a demonstrated, explicitly scoped application.
